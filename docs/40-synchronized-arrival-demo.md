# 도착 후 시연 · 시간에 맞춘 화면과 앱 비교

2026-11-14 UTC. 사용자 지적에 따라 화면별 자산을 따로 끼워 넣던20초 합성을 **같은 방문의 시간순72초 UX 시연**으로 교체했다. 현재 대표 검토본은 [백화점72초](evidence/demo-video/store-arrival-v2/README.md)다. 기존 영상·앱·데이터를 지우지 않는다.

## 고정한 경험

**이동 중에는 첫 번째 차량정보를 유지하고 내비가 두 번째·세 번째 영역을 사용한다. 목적지에 도착한 뒤에만3분할로 전환해 도착자리 안내를 연다.** 내비 경로 계산 완료를 도착/입차/주차 완료로 취급하지 않는다. 영상의 전환은 연출이며 실제 SDK/분할 API 성공이 아니다.

| 시점 | 차량 / 가운데 내비 | 세 번째 상단 | 세 번째 하단 |
| --- | --- | --- | --- |
| 0–8초 도로 이동 | 주행 상태 연출 / 넓은 도로 안내 | 서비스 화면 숨김 | 내비가 이 영역까지 사용 |
| 8–10초 목적지 도착 | 내비가 줄며 도착 카드 표시 | 패널 열기 전환 | 주차 안내로 전환 |
| 10–16초 입차 후 | 주행 상태 / 도로 안내 종료 | 몰 실내 진입부 실사 컷 | 기울인 주차장 배치 예시 |
| 16–28초 주차장 이동 | 같은 도착 상태 | 같은 실사의 이어지는 이동 구간 | 주차 지도, 미확인 층·기둥·위치 유지 |
| 28–36초 주차 동작 | 주행 상태 / 도로 안내 종료 | 동일 제작자 두 번째 컷을 역재생·감속해 접근 연출 | 주차 지도 유지 |
| 36–43초 명시 주차 완료 | P·0 연출 / 도착 상태 | 마지막 정차 프레임 유지, 관측 중지 | 완료 확인, 사용자 터치 연출 |
| 43–50초 승강 안내 | P·0 유지 | 동일 정차 프레임을 상단 축소 | 주차층/승강 연결 미확인,5층 안내 직접 열기 |
| 50–66초 매장 안내 | P·0 유지 | 정차 화면 유지. 이동 영상 반복 금지 | 기존 catalog 기반5층 개략도/파란선8초 재생+유지 |
| 66–72초 닫기 | P·0 유지 | 카메라 꺼짐 | 방문/주차 단서 요약. 자동 재생 없음 |

주차 완료/5층 열기/닫기는 영상의 터치 표시로 사용자 행동을 표현한다. 실제 터치/저장ACK/프로세스 복원 증거는 기존 앱 기기 기록과 따로 대조한다.5층 안내를 보여주면서 상단에서 차가 계속 이동하는 편집을 금지한다.

## 자료와 연출 경계

- [gusat silviu / Pexels 실제 몰 실내 영상 두 컷](media/mall-parking/README.md)을 선택했다. 노란 기둥과 회색 실내가 이어지지만 **동일 실제 방문/판교점/차량 탑재 촬영을 확인한 자료는 아니다.** 주차 완료를 실제 촬영한 기록으로 주장하지 않는다.
- 실제 백화점 외부 입구부터 주차까지 전 구간의 연속 전방 차량 영상은 확보하지 못했다. 이번 영상은 입차 후 실내 컷으로 시작하며 실제 외부 진입 성공이나 후방 카메라 영상을 만들어 넣지 않는다.
- 주차 동작은 두 번째 컷7.5→5.5초 역재생·감속, 주차 후는5.5초 프레임 유지다. “실사 주차장·편집 연출/정차 화면 연출”을 영상에 표시한다. 카메라를3D로 모델링하지 않는다.
- 주차 지도는 공간 배치 예시이고 촬영 장소 지도/층과 연결되지 않는다. 지도에 현재 위치 점·기둥 번호·승강기 호기·허구 거리를 추가하지 않는다. 영상에서 새 OCR을 실행하지 않았다.
- 5층은 기존 공식 기반 catalog/앱 도형 좌표로 다시 그린 개략도다. 새 앱 캡처나 사용자 측위가 아니다. 주차층→해당 엘리베이터 연결은 확인이 필요하다는 안내로 분리한다.
- 차량/내비 배경은 기존 승인 생성 시안, 차량 상태/내비 경로·도착 카드/분할 전환은 영상 연출이다. 실제 Pleos3분할이나 SDK 요청/핀 검증은 Mac에서 별도 필요하다.

| 상황 | 카메라 자료 | 하단 지도 / 종료 기준 |

병원/학원/역/공항의 새 연속영상은 이번에 제작 완료하지 않았다. 기존 정지 시안이나 백화점 클립을 각 장소의 새 영상으로 바꾸어 표시하지 않는다.

## 앱과 비교한 다음 구현

[장면별 실제 차이](evidence/demo-video/store-arrival-v2/app-comparison.md)를 기준으로 후속 앱을 수정한다. 순정 내비 확장/축소를 앱이 제어할 수 있는지는 공식 API/실제 Pleos에서 확인해야 한다. 미지원이면 수동 창 배치를 표시하고 합성처럼 자동 제어했다고 주장하지 않는다. 기존 수동 매장 동선 미리보기는 별도 미리보기로 보존하며, **도착 후 자동 시연 흐름에서는 주차 완료 이후에만 매장 안내를 제안**한다.

이번 커밋은 영상·편집기·명세·비교 기록이다. 앱은0.11.0/11·f0640b0 및 기존APK를 유지한다. 새 앱/새 기기 검사로 표시하지 않는다.
