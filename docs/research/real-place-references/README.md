- 공식 병원 주차 사진과 방문자 사진, 보도사진, 학원 정보 페이지, 정자역 사진 모음을 각각 구분한다. 모든 사진의 촬영일/촬영좌표를 검증한 것은 아니다.
- 날짜가 오래된 사진의 표지·전광판·요금·운영 정보는 현재 상태의 근거가 아니다. 페이지 수정일과 사진 촬영일도 다르다.
- 공항 장기주차장 사진을 요청에 따라 확보했지만, 짧은 마중 대기에 장기주차장이 적합하다는 추천을 검증한 것은 아니다. 단기/장기/예약 주차와 승차 허용 구역을 따로 검토해야 한다.
- 병원 출입구/승강기 연결, 학원 픽업 허용점, 정자역 승차·대기 규정은 사진만으로 확정하지 않는다.
- 차량 표지의 관측은 사진 시각 검토이며 앱 ML Kit/실차 카메라 OCR·측위·내비 핀 검증이 아니다.
