# 6단계 · 명시 주차 완료·저장 확인·요약·귀환

2026-11-13 UTC · docs/07 범위/18 단계. 앱0.8.0/8. 현재 구현/검사 중이며 실제 완료 수준은 docs/08과 증거를 따른다.

## 같은 방문의 별도 주차 기록

입차가 기록된 PARKING_GUIDANCE 방문에서 직접(USER) 또는 표시된 TEST 주차 완료를 확인한다. 정차·입차·OCR만으로 완료하지 않는다. completion ID/확인 시각/확인 방식/차량 상태 출처를 별도 parked JSON에 기록한다. 기존 SQLite schema1·방문/시설 snapshot·road/observation·legacy ParkingClue·설정/좌석·알림 저널은 유지한다. 옛 JSON은 빈 주차 이력으로 읽는다.

완료는 phase=PARKED/visibility=HIDDEN과 모든 미완료 관측 저널 중지를 같은 방문 payload에 저장한다. 런타임 generation은 저장 전에 무효화하고 native 결과를 차단한다. 저장 실패에도 관측을 자동 재개하지 않는다. 저장 후 실제 SQLite currentVisit을 다시 읽고 요청한 전체 값과 같을 때만 성공을 알린다. UI 입력 변경·저장 중·성공·확인 실패를 구분한다. 쓰기 후 재조회/응답 유실은 저장 결과 미확인으로 표시하고 롤백되었다고 단정하지 않는다.

완료만 누르면 위치 단서는 미확인이다. 생성 C12/TEST B3·B4/기존 관측·옛 ParkingClue를 새 확인값으로 복사하지 않는다. legacy ParkingClue는 원본 보존용이며 새 parked 기록과 구분한다. 수동 단서는 별도 revision ID/USER 또는 TEST/확인 시각/층·구역·기둥·승강기·메모로 저장한다. 빈 필드도 허용한다. USER는 사용자의 입력 확인이며 실제 현장/시설 연결 검증이 아니다. TEST 채우기는 실제 판교점이 아닌 fixture이고 편집해도 TEST 출처를 유지한다. '비우고 직접 입력'은 폼을 지운 뒤 USER 입력으로 시작한다.

최대16회 주차/회당32번 단서 수정, 식별 필드64자/메모280자다. 한도를 넘으면 오류로 보류하고 이전 기록을 삭제하지 않는다. 이미 사용한 completion ID나 활성 주차가 있으면 반복 완료는 새 기록/요약을 만들지 않는다. revision ID는 같은 내용만 재시도할 수 있다. 순차 writer로 연속 수동 저장을 처리하고 마지막 요청 완료만 최신 상태로 표시한다. 저장 중 새로 편집한 값은 미저장으로 남는다. 실패한 요청 재시도는 같은 ID·내용·확인 시각을 유지한다. 응답/재조회 유실 후 재시도도 중복 기록을 만들지 않는다.

## 요약·닫기·귀환

저장 ACK 후 정차 상태와 화면 generation이 유지될 때만 일회성 요약을 연다. 기본8초 후 닫으며 현재 실행에서8초 자동닫기/끄기를 선택할 수 있다. 재시작 후 설정 기본8초로 돌아가지만 요약 자체는 자동으로 열지 않는다. 요약/귀환 화면은 저장한 단서·출처/시각과 미확인을 표시한다. 닫기/뒤로/탭이탈/백그라운드/종료/주행 또는 unknown은 화면·관측을 중지한다. 동일 이벤트/반복 완료/재시작으로 다시 열지 않는다. 성공이 확인되지 않은 완료 요청을 명시적으로 다시 저장한 경우만 성공 요약을 허용한다.

'차로 돌아가기'는 저장 기록을 명시적으로 연다. 현재 위치·주차층↔승강기·복귀 연결 근거가 없어 경로/거리·역방향 선을 생성하지 않는다. 저장된5층 개략도는 엘리베이터→에뜨와의 매장행 동선으로만 수동 열기 제공하며 차량 복귀선이라고 표시하지 않는다. 화면을 닫아도 방문/주차/알림 기록은 남는다.

## 이동 재개와 종료 복원

명시적 '주차 위치 변경·다시 찾기' 또는 실제로 수신한 stopped=false 상태는 활성 주차에 재개 시각/차량 입력 출처/명시 여부를 남기고 PARKING_GUIDANCE/HIDDEN으로 전환한다. 이전 단서는 이력으로 보존하지만 현재 주차 위치로 표시하지 않는다. 영상/지도/내비를 자동 시작하지 않는다. TEST 이동과 실제 SDK 신호를 구분한다. unknown만으로 실제 이동했다고 기록하지 않고 상세 화면을 숨긴다.

저장 중 또는 ACK 유실 후 이동이 발생해도 같은 요청 ID의 과거 확인을 복구하고, 요약을 띄우지 않고 해당 주차를 이전 기록으로 바꾼다. 늦은 이전 주차 ID의 이동/완료/단서는 새 주차를 바꾸지 않는다. 새 완료는 새 ID의 기록이며 이전 단서를 자동 복사하지 않는다. 프로세스 재시작은 같은 방문/주차/단서 revision·출처/시각을 읽고 모든 화면/관측은 idle로 시작한다. 미저장 폼은 저장 완료로 복원하지 않는다. SMS pending/unknown은 같은 확정 요청의 기존 복구 계약을 유지한다.
