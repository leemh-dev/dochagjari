# 현대 양재 사옥 출발 · 더현대 서울 매장 방문 개발계획

2026-11-13 KST · 사용자 지정 시나리오/개발 계획. 앱 구현·시설 조사 완료 증거가 아니다. 제출 범위의 최신 구체화이며 [docs/07](07-development-plan.md)과 [검증 기록](08-verification.md)을 함께 따른다.

## 이번 시연의 고정 범위

- 출발지: 현대자동차 양재 사옥. 사옥의 실제 차량 출차 지점/좌표는 공식 주소와 지도/현장 근거로 확인 후 등록한다. 건물 대표 좌표를 출차 지점으로 추정해 확정하지 않는다.
- 방문 지점: **더현대 서울 한 곳**을 1차 대상으로 선택한다. 현대백화점 전 지점·다른 몰 전체를 이번 데이터 수집 대상으로 확장하지 않는다.
- 방문 목적: “현대 양재 사옥에서 출발해서 더현대 서울의 ○○ 매장에 가고 싶어.” 대표 후보는 **나이키 매장**으로 두되, 최신 공식 입점 여부·정확한 매장명·층을 확인한 뒤 확정한다. 현재 입점/층수 확인을 완료한 것으로 표시하지 않는다.
- 첫 완성은 대표 매장 한 곳의 전체 흐름이다. 데이터 구조에는 다른 목적지를 수용하되, 두 번째 실제 매장은 첫 흐름이 동작하고 연결 근거가 확보됐을 때 목적지별 추천 비교용으로 추가한다.
- 일반 방문 조건을 먼저 연결하고 유모차/휠체어 조건 한 가지를 추가 비교한다. 확인된 접근 연결이 없으면 충족한다고 추천하지 않는다.
- 목표: 개발 서명 APK로 기능 검증과 시연영상. 앱마켓 출시/출시용 키·제휴 체결·전국 커버리지는 이번 완료 조건이 아니다.

고정 출발지는 **데모 여행 계획의 출발지**다. 순정 내비가 현재 차량 위치를 출발점으로 삼는 경우, 앱에서 사옥을 선택했다고 실제 차량/AVD 위치가 바뀐 것으로 주장하지 않는다. 공식 시뮬레이션 위치 입력이 지원되면 이를 별도 기록하고, 미지원이면 고정 출발지 계획과 실제 내비 목적지 전달을 나누어 검증한다. 가짜 현재 위치를 실제 GPS로 표시하지 않는다.

## 한 번에 보여줄 사용자 흐름

1. 출발지 “현대자동차 양재 사옥”이 고정된 상태에서 방문 매장을 선택하거나 입력한다.
2. 시스템이 더현대 서울의 해당 매장·층을 식별하고, 공식 자료와 최신 관련 리뷰의 근거를 묶는다. 동명이거나 해당 지점에 없는 매장은 확인/검색 실패를 표시한다.
3. 매장에 연결되는 엘리베이터와 주차 구역·층, 차량 게이트를 묶어 추천한다. 출처와 추천 이유, 미확인 구간을 보여준다.
4. 사용자가 확인하면 검증한 차량 게이트 좌표를 Pleos 내비에 전달한다. 실제 SDK 결과와 순정 핀을 각각 확인한다.
5. 입차를 확인한 후 카메라/명시한 주차 영상에서 주변 층·구역·기둥/벽 표기를 관측한다.
6. 최종 정차 부근 단서를 확인해 이 방문의 실제 주차 위치를 저장한다. 계획한 구역과 실제 주차한 구역을 구분한다.
7. 매장 방문 후 “차로 돌아가기”를 열면 저장한 층·구역·기둥/사진 단서와 확인된 엘리베이터 연결을 보여준다. 앱 재시작 후에도 기록이 유지된다.

주차장을 포함한 전체 실내 정밀 길안내를 첫 버전의 조건으로 삼지 않는다. 확보한 연결과 단서 안내 범위를 표시하며, 실제 이용하지 않은 엘리베이터를 이용했다고 저장하지 않는다.

## 조사 게이트와 대체 동작

- 먼저 공식 매장/층·주차 안내를 확인하고 관련성이 맞는 최신 리뷰로 연결 팁을 보완한다. 최신 글이라는 이유만으로 공식 변경 공지나 현장 확인을 무시하지 않는다.
- 나이키 후보의 입점/연결 근거가 부족하면 같은 더현대 서울 안에서 공식 자료가 확인되는 매장으로 대표 매장을 바꾼다. 더현대 서울 전체의 핵심 연결 자체를 확보하지 못하면 차단 항목을 기록하고 현대백화점 다른 지점 한 곳으로 바꿀 근거를 제시한다. 근거 없이 지점을 늘리지 않는다.
- 시설 연결이 부족하면 확인된 부분까지 UI에 표시하고 현장 확인/시설 문의/제휴 필요 항목으로 기록한다. 문의/제휴를 이미 수행했다고 주장하지 않는다.
- 외부 카메라 미지원은 카메라 입력 어댑터의 사전 영상으로 개발을 계속할 사유다. 도착 계획/저장/귀환 구현을 전체 중단하지 않는다. 내비 경로 계산 완료는 입차가 아니며 명시적 입차 테스트 입력을 제공한다.
- 관측 표기가 없으면 정확한 면 위치 대신 마지막 확인 단서와 사용자 사진/메모를 저장한다. 시설 지도에 없는 정밀 위치를 만들어내지 않는다.
