# 서비스 시나리오

2026-11-13 사용자 방향 확정: **초행 장소·건물·주차장에 익숙하지 않은 사람**을 중심으로 네 대표 시나리오를 다룬다. 매장 방문은 시나리오 1이며 서비스 전체를 뜻하지 않는다. 역·공항 마중도 대표 시나리오 4로 포함한다. 주차 표지 관측은 여러 시나리오의 공통 기능이다. [고도화 방향](26-service-continuation.md).

| 대표 시나리오 | 이용자의 목적 | 핵심 안내 | 현재 근거의 경계 |
| --- | --- | --- | --- |
| 1. 매장 방문 | 판교점 에뜨와 등 실제 방문 목적지에 가기 | 차량 접근·주차 구역·승강기·매장행 동선과 귀환 | 확인된 시설/5층 자료와 미확인 주차장 연결을 구분 |
| 2. 병원 동행 | 동행 조건에 맞게 진료 목적지에 가기 | 먼저 하차 후 주차 또는 함께 주차·무단차 동선 | 실제 허용점/연결 미확인은 가상 시연 유지 |
| 3. 등하원·픽업 | 아이와 실제로 만날 곳에 가기 | 바로 태우기·대기·직접 데리러 가기·막힌 후보 우회·만남 알림 | 가상 시설/테스트 입력·모의 발송과 실제 연동 구분 |
| 4. 역·공항 마중 | 낯선 터미널/출구에서 일행과 만나기 | 도착층/출구·승차 가능 지점·대기 주차장·만남 단서 연결 | 실제 시설/규정·현재 이용 가능 여부·도착 정보 연동은 미검증 |

좌석/유모차/휠체어 조건·자료 조사/DB·내비·관측·주차 기억·알림은 공통 기능이다. 아래 기존 세부 상황은 보존한다. 표는 기획 분류이며 구현 완료 목록이 아니다. 역·공항의 대표 시나리오 편입이 11월15일 추가 구현/시설 연동 완료를 뜻하지 않는다.

## 초행 이용자가 이해해야 할 것

1. 내가 갈 시설의 정확한 지점/진료동/매장/터미널·출구는 어디인가?
2. 차량은 어느 진입점으로 가고, 사람은 어느 출구/보행 동선을 이용하는가?
3. 바로 승하차할 수 있는가, 대기하거나 주차해야 하는가?
4. 차에서 내려 어디로 가거나 일행에게 어떤 만남 단서를 알려야 하는가?
5. 주차했다면 돌아올 때 어떤 저장 단서로 차를 찾는가?

해당 시나리오에 필요한 질문만 답하고, 자료가 미확인인 항목은 미확인과 확인 방법을 표시한다. 출구 번호나 대기 가능 시간을 추정으로 채우지 않는다.

## 기존 세부 상황

| 상황 | 운전자가 필요한 것 | 앱의 동작 |
| --- | --- | --- |
| 학교 등교 | 아이가 이용하는 문에 가까운 하차 지점 | 선택한 보행 출입구에 연결되고 일반 차량의 이용 조건이 확인된 하차 지점을 추천한다. |
| 학교·학원에서 바로 태우기 | 아이와 만날 곳, 차가 접근할 곳 | 만날 문과 차량 접근점을 함께 표시한다. 확인된 보행 경로가 있다면 횡단 부담이 적은 후보를 우선한다. |
| 학원에 일찍 도착 | 기다릴 수 있는 주차장 | 대기 예정 시간과 운영시간·요금을 반영해 주차장 입구를 추천한다. |
| 보호자가 직접 데리러 가기 | 주차 후 실제 출입구까지 걸어가는 길 | 주차장 차량 입구로 안내하고, 주차 구역에서 만날 문까지 도보 안내를 보여준다. |
| 골목 목적지나 정문 앞이 막힌 경우 | 진입 가능한 다음 승하차점 또는 주차장 | 사용자가 해당 지점을 이용할 수 없다고 표시하면 다음 후보를 찾는다. 적합한 승하차점이 없으면 주변 주차장을 안내한다. |
| 병원에 유모차를 싣고 방문 | 카시트 쪽 문 여유, 계단 없는 동선 | 저장한 좌석·유모차 조건을 적용한다. 문 여유가 확인된 구역을 우선하고 확인된 엘리베이터 연결을 제공한다. |
| 휠체어 이용자와 병원 방문 | 동승자 하차 후 주차하거나 함께 주차하는 동선 | 먼저 내려도 되는 경우 하차점과 후속 주차를 연결한다. 동행이 계속 필요하면 함께 주차한 뒤 무단차 경로로 이동하는 후보를 제시한다. |
| 쇼핑몰에서 높이 제한 또는 만차 | 차량이 진입할 수 있는 대체 주차장 | 확인된 높이 제한과 차량 높이를 비교한다. 실시간 현황이 연동된 곳은 관측 시각과 함께 만차 상태를 반영한다. |
| 역·공항에 마중 가기 | 올바른 출구의 승차점 또는 대기 장소 | 터미널·출구와 이용 시간에 맞는 지점을 안내한다. 대기가 길어지면 주차장으로 전환할 수 있다. |
| 정차한 뒤 상대에게 연락 | 지금 만날 위치와 찾기 쉬운 단서 | 실제 정차점을 확인하고 지도 링크와 출입구·층·기둥 번호를 공유한다. |

## 대표 시연 흐름

1. 가상 학원과 동일한 보행 출입구를 선택한다. **바로 태우기**를 고르면 확인된 승하차점이 표시된다.
2. **주차하고 데리러 가기**로 바꾸면 차량 도착점이 주차장 입구로 바뀐다. 사람 출입구와 도보 연결을 함께 보여준다.
3. 바로 태우는 상황에서 최초 승하차점이 막혔다고 입력한다. 다음 승하차점이 없으면 주차장 입구가 추천된다.
4. 정차한 뒤 **여기서 만나요**로 실제 정차 위치와 기준점을 확인하고 휴대폰에서 공유 문구를 연다.

시연 데이터는 가상으로 표시한다. 실제 내비 연동 시연에 쓸 좌표는 경로가 성립하는 테스트 지점을 검증해 별도로 선택한다.

## 공통 예외 처리

- 확인된 승하차점이 없으면 확인 가능한 주차장으로 넘어간다. 주차장 후보도 없으면 현재 위치를 정차점으로 제안하는 대신 후보 없음 상태를 표시한다.
- 지하에서는 마지막 GPS 좌표와 추정 층을 자동 확정하지 않는다. 시설 안내 또는 사용자가 확인한 층·구역·기둥을 보여준다.
- 주차장 이용 가능 시간과 실시간 빈자리 확인 여부를 화면에서 구분한다.
