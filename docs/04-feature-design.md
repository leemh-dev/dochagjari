# 기능 설계

## 추가한 핵심 설계 — 방문 목적 계획과 주차 이후 관측

실내 목적지 입력→최신 자료/시설 연결 검색→게이트·구역·엘리베이터 계획→내비 전달→입차 확인→주변 표기 관측→정차 위치 확인·저장→귀환으로 이어진다. 공공/공식/리뷰/제휴 경로를 조합하고 미확보 항목의 대체 동작을 설계한다. 이는 구현할 목표이며 기존 앱 검사 통과와 구분한다.

카메라는 입차 후 지원되는 프레임에서 기둥뿐 아니라 벽/층/구역·방향 표지를 관측한다. 주행 중 영상 UI를 표시하지 않는다. 표기 없는 경우 정확한 위치 미확인과 마지막 단서/수동 보완을 제공한다. 경로 계산 완료와 입차/최종 주차를 혼동하지 않으며 이동 재개 시 임시 위치를 갱신한다. 카메라 미연동 환경도 사전 영상 어댑터로 동일 로직을 검증한다.

상태·저장 필드·카메라 권한/대체 경로·시험 항목은 [주차 관측 상세 설계](14-data-and-parking-observation.md)를 따른다.

## 설정과 추천

| 기능 | 동작 |
| --- | --- |
| 즐겨찾기 | 시설과 사람 출입구를 함께 저장한다. 즐겨찾기마다 기본 방문 모드를 정할 수 있다. |
| 좌석별 옵션 | 카시트 쪽 문 여유, 유모차, 무단차 동선, 휠체어 적재 공간, 보호자 동행 필요를 정차 중 설정해 재사용한다. 탑승자 이름과 진단 정보는 수집하지 않는다. |
| 좌석 점유 | 지원 시 저장 옵션의 적용을 제안한다. 점유·비점유·알 수 없음을 구분한다. 지원되지 않거나 읽기 권한이 없으면 저장 옵션을 직접 선택한다. |
| 차량 조건 | 차량 높이를 설정하고 루프박스 등 추가 장비를 반영할 수 있게 한다. Pleos 차량 제원은 지원 여부를 확인해 초기값 후보로 사용한다. |
| 추천 화면 | 만날 문, 차량 도착점, 추천 이유, 확인된 제한과 보행 안내를 표시한다. |

### 추천 순서

1. 시설과 사람 출입구에서 해당 방문 모드에 맞는 후보를 가져온다. 보호자 동행이 필요한 경우 동승자를 먼저 내려두는 흐름을 제외한다.
2. 사용 불가 상태, 운영시간, 차량 제한을 적용한다. 무단차 등 필수 조건이 미확인이면 충족으로 처리하지 않는다.
3. 남은 후보를 확인된 보행 경로, 횡단 부담, 문 여유, 대기 목적에 따라 정렬한다. 탈락 또는 미확인 사유를 표현할 수 있게 한다.
4. 선택한 접근점으로 내비 경로를 요청한다. 실패하면 재시도 또는 다른 후보를 선택할 수 있는 상태를 제공한다.

## 입구 앞에서 정차할 수 없을 때

- 이용 불가로 표시된 후보를 이번 방문에서 제외한다. 이용 조건이 확인된 대체 승하차점이 있으면 만날 출입구까지의 거리를 함께 보여준다. 직접 데리러 가거나 기다려야 하면 주차장 입구를 우선한다.
- 주행 중 조작 범위는 Pleos 주행 제한을 따른다. 조작이 제한되면 순정 내비 화면을 유지하고, 정차 후 대체 후보를 확인할 수 있게 한다.
- 카메라 확장에서는 이동 중 운전자에게 카메라 화면을 보여주지 않고, 연동이 가능한 경우 등록된 후보 구간의 차량·장애물 점유 여부만 판단한다. 도로에 차가 없다는 관측으로 이용 허용을 추론하지 않는다. 관측 시각을 기록하고, 가림이나 저조도로 확신이 낮으면 미확인으로 처리한다.
- 정차 후에는 표지나 기둥 번호 등 만남 위치의 단서를 제안할 수 있다. 공모전에서 카메라 기능을 시연한다면 사전 촬영 영상 사용 여부를 화면에 표시한다.

## 정차 위치 공유

1. 정차 상태에서 **여기서 만나요**를 누른다. 앱은 이용 가능한 위치 신호 또는 사용자가 지정한 핀을 제시한다. 추천 도착점과 실제 정차점이 다르면 수정할 수 있다.
2. 지하에서는 시설명, 층, 구역, 기둥 번호를 확인해 공유 문구에 넣는다. 필요하면 시설 입구를 지도 링크에 사용하고, 실제 만남 지점은 텍스트로 설명한다.
3. 예시 문구는 “건물 뒤편 주차장 B1, C12 기둥 옆에 있어요. 1층 서쪽 출입구에서 내려오면 됩니다.”이다.
4. 1차 구현은 휴대폰으로 넘길 문구와 위치 링크를 제공하고, QR 또는 가능한 공유 방식으로 휴대폰에서 연다. 수신자와 내용을 확인한 뒤 문자 또는 카카오톡으로 보낸다.
5. 사전 등록된 상대에게 자동으로 도착 알림을 보내는 기능은 동의·수신 설정·발송 결과 확인이 가능한 채널을 확보한 뒤 검토한다. 카카오톡 공유에는 사용자가 대상 선택을 하는 단계가 있다.

공유 문구에는 위치와 필요한 만남 단서만 담는다. 좌석 옵션, 차량 영상, 연락처는 공유 링크에 포함하지 않는다. 앱은 공유 화면을 열었는지와 실제 발송이 확인됐는지를 구분한다.
