# 데이터 확보·검증 계획

| --- | --- | --- |

| 승하차 구역 | 시설 운영자 또는 관할 기관 확인과 현장 표지 | 일반 차량 허용 여부, 시간·차량·용도 제한, 연결되는 보행 출입구 |
| 보행 경로 | 시설 층별 지도와 현장 확인 | 횡단, 엘리베이터 연결 층, 문턱·계단·경사로, 통행시간 |
| 주차장 여유와 면별 점유 | 공공·운영사 API가 있는 곳만 연결 | 시설 총 여유와 면별 점유를 구분하고 관측 시각과 누락을 기록 |

## 실제 시설 조사 결과

| 후보 | 공개 자료로 확인한 내용 | 추가 검증이 필요한 내용 |
| --- | --- | --- |
| 용인세브란스병원 | 본관 B1~B3, Y-center 엘리베이터, P2 타워와 1층 시설 안내 | 실제 차량 입구 핀, 일반 차량 하차점과 허용 시간, 높이 제한, 주차 구역에서 진료과까지 무단차 경로 |
| 수지초등학교 | 학교 공식 주소 | 등하교 문, 일반 자가용에 허용된 승하차 지점과 시간 |
| 수지씨앤씨미술학원 | 학원 공식 주소와 층·호수 | 보행 출입구, 차량 진입 차로, 주차 운영 조건과 승하차 구역 |
| 인천공항 T1 단기주차장 | 면 번호·구역·점유 상태를 제공하는 공공 API 명세 | 인증 후 응답, 도면의 면 번호와 API ID 매핑, 다른 시설로의 적용 범위 |

공개 안내와 API 명세를 검토했다. 실제 API 인증 호출, 현장 답사, 운영자 확인은 남아 있다. 위 시설의 미확인 좌표나 이용 조건은 실제 추천 데이터에 넣기 전에 검증한다.

## 저장 구조와 연결

| 레코드 | 최소 항목 |
| --- | --- |
| 시설 | 자체 ID, 이름, 정규화 주소, 건물 식별자, 출처별 ID |
| 지점 | 자체 ID, 시설·주차장 ID, 지점 유형, 좌표, 운영시간, 이용 제한, 안내 문구 |
| 보행 연결 | 시작·끝 지점 ID, 거리, 층 이동, 횡단, 무단차 확인 상태 |
| 주차 현황 | 시설·구역·면 중 집계 단위, 점유 상태 또는 여유대수, 관측 시각 |
| 검증 기록 | 출처 URL 또는 확인 방법, 확인일, 확인 상태, 적용 범위 |

시설과 주차장 사이에는 다대다 연결을 허용한다. 예를 들어 하나의 공영주차장이 여러 학교·학원의 대체 지점이 될 수 있다. 동일 시설 여부를 주소·공급자 ID·좌표로 대조하고, 차량 입구의 좌표는 시설 대표 주소 좌표와 별도로 기록한다.

## 갱신과 적용 기준

1. 공모전에서는 가상 시연 데이터와 확인된 시설 데이터를 구분하고, 소량의 시설 데이터를 앱에 동봉한다.
2. 일반 자가용의 승하차 허용 여부와 필수 무단차 동선은 확인된 항목만 추천에 사용한다. 어린이 보호구역 등에서 예외가 필요한 경우 해당 지점의 지정·표지와 적용 조건을 확인한다.
3. 전국 확대 시 원본 갱신일과 현장 확인일을 별도로 관리한다. 제한 정보가 상충하면 추천에서 제외하고 운영자 확인을 거친다. API별 이용 조건과 재배포 범위를 확인한다.
4. 실시간 데이터가 없는 시설에도 기본 주차장 검색을 제공한다. 면별·도어 여유 추천은 해당 면의 점유, 배치, 장애물과 방향을 확인할 수 있는 경우에 제공한다.
