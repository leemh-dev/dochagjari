실제 도로를 전방에서 촬영한 **해외 사전 영상**이다. 판교점 주차장·현재 차량 위치·실시간 OEM 빌트인캠이 아니다. 얼굴/번호판을 식별·확대하는 증거로 사용하지 않는다. 이 영상에서 OCR을 실행하지 않았고 층·기둥 번호를 만들지 않았다. 아래5층 지도와 위치가 연결돼 있다는 뜻도 아니다.

이번 적용은 [3분할 예상도](../../evidence/demo-video/three-panel-concept/README.md)의 세 번째 상단이다. **앱/APK에는 이 클립을 새로 동봉하지 않았다.** 기존 APK의 생성 C12는 별도 회귀용 테스트 입력으로 남으며 실제 판교점 위치로 사용하지 않는다.

전방 카메라에 맞는지 프레임을 직접 열람했다. 먼저 조사한 Monmouth Mall 영상은 측면 촬영이어서 제외했다. 영상 자체를3D로 바꾸지 않으며, 기울인 지도만 별도 하단에 유지한다.
