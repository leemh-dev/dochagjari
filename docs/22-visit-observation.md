# 5단계 · 같은 방문의 관측과 추천 갱신

2026-11-13 UTC. 범위는 docs/07, 전체 순서는 docs/18. 앱 0.7.0/7.

## 입력과 저장

명시 입차가 저장된 PARKING_GUIDANCE 방문에서만 관측을 시작한다. 시설/방문 ID와 catalog 버전·기존 설정/좌석 역할·확정 알림은 바꾸지 않는다. 기존 SQLite schema1의 방문 JSON에 선택적 observation을 추가하며 옛 JSON은 빈 관측으로 읽는다.

TEST/생성 영상/선택 영상/공개 영상을 구분한다. 실제 외부 카메라는 공식 접근 경로·권한·프레임 제공이 검증되지 않아 연결하지 않았다. URI·파일 경로를 저장하지 않고 관측 ID/출처·분석 시각·클립 시각·최대1000자 원문(잘림 표시)·문자 confidence(nullable)·점유/점수·중지 사유를 저장한다. 최대8회/회당24프레임이다. ML Kit Text Recognition은 이 코드 경로에서 confidence를 제공하지 않으므로 null이며 객체 검출 점수를 문자 신뢰도로 대체하지 않는다. 영상 분석 시각은 촬영 시각이나 현재 차량 위치가 아니다.

앱 소유 FIFO 저장을 사용한다. 저장된 현재 run ID만 프레임을 받는다. source 변경/중지/늦은 프레임은 이전 run을 수정하지 않는다. 샘플 ID 중복은 반복 관측 수로 세지 않는다. 저장 IO 오류는 기존 repository 오류 표시로 남고 확정 위치로 승격하지 않는다.

## 보수적 단서 판정

- 최근30초 이내의 연속된 두 실제 처리 프레임에서 동일한 표지여야 문자 후보가 된다. ML Kit 점수 미제공은 반복된 미확인 문자 후보일 뿐 검증된 위치가 아니다. 명시 점수0.65 미만·미래/오래됨·표기 없음·여러 표기는 후보를 보류한다.
- `FLOOR B3 C12`, `B3F C12`, `지하3층 C12`처럼 층 표기가 명시된 경우만 층 문자 후보로 읽는다. `B3 C12`는 두 기둥 번호일 수 있어 추정하지 않는다. 같은 번호의 B3/B4 관측이 겹치면 충돌로 보류한다.
- 반복 장애물 관측은 주의 문구를 갱신한다. 실제 주행/정차 허용이나 측위·통행 연결을 확정하지 않는다.
- 생성 C12는 실제 판교점 기둥이 아니다. 후보의 층은 인식한 텍스트이며 차량 주차층이 아니다. `visit.parking`은 null을 유지한다. 확인된 기둥↔주차층↔승강기 연결 DB가 없어 승강기/현재 위치·연결 경로를 생성하지 않는다. 기존 공식5층 개략도의 경로는 유지하고 지도에도 출처·미확인 추천 문구를 표시한다. 실제 연결 자료가 생긴 뒤 별도 계획 revision으로 갱신할 수 있다.

## 중지·철회·복원

닫기/관측 중지/방문 탭 이탈/백그라운드 ON_STOP/화면 해제/주행 또는 상태 미확인/입력 소스 변경/ViewModel 종료는 generation을 먼저 무효화한다. 늦게 도착한 native 결과는 저장하지 않는다. 앱 cache/files의 canonical 하위 읽기 가능한 file://는 앱 소유 파일로 구분한다. 외부 파일은 picker의 content URI를 사용하며, 선택 문서의 URI read 권한을 프레임 사이에서 재확인하고 SecurityException이면 중지한다. UI의 '입력 권한 철회 테스트'는 모의 중지이며 실제 OS 권한 철회 성공으로 표시하지 않는다.

네이티브 detect/OCR 호출은 진행 중인 한 호출이 끝나거나 OCR 제한시간(15초)에 도달한 뒤 finally에서 retriever/detector/recognizer/bitmap/temp를 해제한다. 즉시 native 강제중단을 보장하지 않는다. 앱 공통 Mutex로 이전 해제 전 새 분석기를 겹쳐 만들지 않는다. 재시작은 저장 단서만 보여주고 입력/카메라를 자동 재개하지 않는다. 강제종료는 종료 사유를 쓸 기회가 없을 수 있어 종료 사유 없는 저널도 자동 재개하지 않는다.
