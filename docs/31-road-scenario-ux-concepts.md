# 도로변 시나리오 UX 시안

2026-11-13 UTC. [실제 이미지19장 조사](30-road-ui-reference-review.md) 후 사용자가 해당 사진으로 우리 시나리오의 디자인을 만들어 달라고 요청했다. [정정한 화면 구조](29-photo-based-3d-ux.md)를 유지해 학원·병원·역·공항 도로변 시안4장을 만들었다. [최종 이미지 모음](ux/road-scenario-concepts/README.md) · [지시/참고출처/실제 치수/SHA256](ux/road-scenario-concepts/metadata.json).

## 공통 구성

첫 번째 차량 정보는 기존 정차(P/0km/h) 차량 모형과 주행 통계 구성을 유지한다. 두 번째도 기존 순정 내비 화면 구성을 유지한다. **세 번째 상단에만 카메라 영상 형태의 프리뷰, 하단에는 기울인3D도로지도**를 배치한다. 카메라를3D로 바꾸거나 첫 번째를 주변상황 화면으로 교체하지 않는다.

왼쪽/가운데는 기존 디자인을 참고한 생성 편집이므로 픽셀 단위 동일성이나 실제 Pleos 실행을 검증한 것은 아니다. 가운데 판교 지도는 분할 구조를 유지한 배경으로, 각 병원/역/공항까지 실제 안내 중이라는 뜻이 아니다. 카메라 프리뷰도 공개 사진을 참고한 생성 이미지이며 원본 카메라 프레임이나 실제 빌트인캠 입력이 아니다. 하단 도로지도는 길/보도/진입/출구 관계를 보여주는 개념도로 실측 지도·위치/거리·허용점 증거가 아니다.

## 장면별 다음 행동

| 장면 | 카메라 영역 | 3D도로지도 | 다음 행동 |
| --- | --- | --- | --- |
| 학원 픽업 | 실제 대치동 픽업 대기 사진을 참고한 야간 도로변 상황 | 학원가·보행로·대기차량/정차금지 구간을 분리 | 대안 장소 찾기 / 만남 위치 공유 |
| 병원 동행 | 분당서울대병원 진입/주차 상황 사진을 참고 | 사람 출입구·주차장 진입·현장확인이 필요한 승하차 후보를 분리 | 함께 주차/먼저 하차를 비교하고 주차 대안/동행 조건 선택 |
| 정자역 마중 | 실제5번출구 표지를 참고 | 출구와 보행 동선 예시만 표시, 차량 승차점은 확인 전 | 승차 장소 찾기 / 만남 위치 공유 |
| 공항 배웅 | 인천공항T1 출국층 승하차/표지 사진을 참고 | 터미널·보도·차로·횡단보도와 승하차/긴 대기의 다른 목적을 표현 | 승하차 안내 / 주차장 보기 |

학원은 확인된 대치동 사진을 쓰므로 분당 현장이라고 표시하지 않는다. 병원 사진의 지하만차 표지는 과거 자료로 현재 만차를 알리는 실시간 결과가 아니다. 병원 지도에 표시한 승하차 후보/입구/주차장은 연결·접근성·이용허용이 검증된 지점이 아니다. 공항은 출국 배웅이며 입국 마중 위치와 같은 것으로 쓰지 않는다. 공항 지도상의 파란 구역도 실제 허용 구역/현장 번호가 아니라 구역 확인 절차를 보여주는 예시다.

## 검토 후 수정

역의 초기 생성본은 차로 중앙에 파란 `승차 장소 탐색` 영역을 그렸다. 승차 위치로 오해할 수 있어 **해당 영역을 지우고 도로 차선만 복원**하는 편집을 수행했다. 최종본은 출구/보행동선만 보여주며 실제 승차점 탐색은 버튼으로 남긴다. 초기 생성 원본은 로컬에 보존하고 metadata에 수정 이유/지시를 기록했다. 최종 파일은 `03-station.png`다.

지도와 카메라의 역할 분리, 다음 행동, 색상/정보 밀도를 검토할 시안이다. 실제 적용 시 문구는 앱 문자열/폰트로 작성하고 최소 글자/터치 크기·주행 제한·지도 자료 정확성·후보 확인 상태를 별도로 검증한다. 이미지에 생성된 글꼴/차량계기 수치는 실기 증거가 아니다. 공유/탐색 버튼이 그려져 있어도 실제 장소 검색/메시지 발송이 구현·실행된 것은 아니다.
