## 유지할 구조와 검토할 내용

[최신 정정](29-photo-based-3d-ux.md)을 유지한다. **첫 번째는 차량정보 그대로, 두 번째는 기존 순정내비 그대로, 세 번째 상단에만 카메라·하단에3D지도**다. 세 번째 하단의 지도 대상이 주차장 내부에서 병원/학원/역 등 도로변 도착구역으로도 확장되는 요청이다. 왼쪽 시스템 ADAS를 앱이 재구현/덮어쓰거나 카메라/건물 외관 영상을3D로 변환하라는 의미가 아니다.

아래는 후속 검토 의제이며 구현/설계 확정이 아니다.

1. 도로·보도·진입로·사람 출입구·차량 목표 구역을3D지도에서 어느 정도 단순화할지 비교한다. 사실감 있는 건물 모형보다 지형/차로 관계의 가독성을 먼저 본다.
2. 카메라 창을 언제 보여줄지 검토한다. 목적지 접근 시 항상 표시할지, 입구/표지를 확인할 때만 필요한지는 아직 정하지 않는다. 실제 카메라 접근 지원도 별도 확인한다.
3. 주차장 관측문자와 도로변 승하차 후보는 다른 자료다. 도로변은 표지/차종/운영구역/시간 조건과 확인 출처를 함께 볼 필요가 있다. 외부 영상에서 여유 공간이 보여도 허용 정차점으로 확정하지 않는다.
4. 병원 동행의 무단차/보호자 하차와 학원 픽업 대기·만남, 역의 사람 출구, 공항의 출국 배웅/입국 마중을 다른 상태로 검토한다. 자료가 없으면 대안 주차/보행 연결도 확정해 그리지 않는다.

## 사진별 과해석 방지와 미확보

- 분당서울대병원 사진은 접근도로/지하주차 진입 대기를 보여준다. 지정된 일반 승용차 승하차 구역/무단차 연결을 증명하지 않는다.
- 서울아산병원 사진은 **다른 병원**의 약국 차량 목적 승하차장이다. 일반 승용차가 쓸 수 있는 병원 앞 정차점으로 바꾸지 않는다.
- 학부모 승용차 픽업 사진은 **대치동**이며 분당으로 표시하지 않는다. 원문은 금지구역 대기 문제를 다루므로 차량 줄을 추천점으로 사용하지 않는다. 분당 셔틀 사진은 셔틀 상황으로 유지한다. 장소/상황이 확인된 분당 학부모 승용차 픽업 사진은 여전히 미확보다.
- 정자역5번출구는 사람 출입구다. 주변에 차가 있다고 차량 승차 허용점을 뜻하지 않는다.
- 공항 사진은T1 출국층이다. 입국 마중에 같은 층/차로/문을 사용한다고 추정하지 않는다. 방문기의 정차 허용 시간/무료주차 주장은 공식 자료 대조 없이 채택하지 않았다.
- 대부분 촬영일을 확인하지 못했고 과거 사진이 포함된다. 현재 정차규정/시설배치/교통상태·거리/위치는 별도다.
