# 판교점 에뜨와 방문 · 기울인 지도와 파란 경로 애니메이션

2026-11-13 UTC · 사용자가 요청한 **앱 외부 시나리오 미리보기**. 앱/APK·실제 내비·실차 이동·주차 기록·실내 측위 구현 증거가 아니다.

- [브라우저에서 조작할 단일 HTML](preview.html): 내려받아 열거나 이 폴더에서 `python3 -m http.server 8765 --bind 127.0.0.1` 후 `http://127.0.0.1:8765/preview.html`로 연다. 지도 이미지/경로가 포함돼 재생에 외부 API나 인증 구성이 필요하지 않다.
- [13초 시나리오 GIF](scenario.gif) · [MP4](scenario.mp4) · [실제 캡처](preview.png) · [모바일 전체 화면](mobile-preview.png).
- 재생/일시정지, 여섯 단계 선택, 재생 위치 슬라이더, 기울기/평면 전환이 동작한다. 동작 줄이기 설정이면 자동 재생하지 않으며 버튼으로 재생할 수 있다.

## 이어지는 안내

1. 양재 사옥에서 현대백화점 판교점 5층 에뜨와 방문을 계획한다.
2. 본관 지하주차장에서 고객용 엘리베이터 표지를 찾아 가까운 빈 주차면을 찾고 실제 주차 층/구역을 기록하도록 안내한다. 특정 차량 게이트·기둥·빈자리 존재를 확정하지 않는다.
3. 현장의 운행층 안내에서5F 정차를 확인하도록 한다.5F 지도에서는 유아휴게실/유아차 대여 쪽 엘리베이터를 출발점으로 사용한다. 주차장 승강기와의 호기 연결은 미확인이다.
4. 지도와 선을 함께 기울이고 공식 보행 연결 좌표를 따라 파란 선과 이동점이 엘리베이터에서 에뜨와까지 진행한다.
5. 에뜨와 도착 후 방문을 마친다.
6. 실제 이용 승강기와 사진/메모에 저장한 주차 층·구역을 확인해 귀환하도록 안내한다. 개인 주차 위치를 가상 번호로 채우지 않는다.

위2·3의 주차장 연결과6의 귀환은 **추정 설명/시나리오 제안**이며 실행한 주행 기록이 아니다. 공식 문화센터의 C1~C3/5·6호기 정보를 에뜨와 전체 연결로 확정하지 않는다. 식별자 우선순위는 `확인한 기둥/구역 → 확인한 승강기 번호/ID → 지도상 주변 시설/매장에 근거한 설명`이다. 마지막 경우 설명의 근거와 미확인을 표시하고 가짜 기둥·호기·거리를 만들지 않는다.

## 2.5D와 근거

[이전 공식 지도 경로 검증](../pangyo-route-example/README.md)의5F 엘리베이터→에뜨와14개 경로점을 사용했다. 같은 뷰포트/지도 카메라의 경로 없는 공식 배경을 새로 캡처해 HTML/SVG로 겹쳤다. CSS perspective/rotateX32°/rotateZ-10°를 지도와 경로에 함께 적용한다. 실제3D 건물 모델이 아니며 이미지 생성 모델로 구조를 재해석하지 않았다.

[원본 공식 층별 안내](https://www.ehyundai.com/newPortal/DP/FG/FG000000_V.do?branchCd=B00148000). SVG선은 시각화 코드로 파란색으로 표현한 것이며 공식 사이트 기본 선 색은 분홍색이다. [좌표 정합 정보](route-alignment.json) 참조. 원시 단위/축척은 m 변환 근거로 사용하지 않는다. 공공 배포/앱에 지도 SDK·자산을 재사용하는 범위는 별도 확인 대상이다. 지도 인증 설정/DOM/브라우저 상태를 포함하지 않는다.

## 실제 확인

- [브라우저 검사](browser-check.json): Chromium1280×850에서 재생/일시정지·단계 선택·기울기 전환 확인, page errors0.390px 모바일 가로 넘침 없음.
- 13초 타임라인을6fps/79프레임으로 캡처 후 ffmpeg로 GIF/MP4 변환했다. 실제 녹화 길이는 약13.17초다. 버튼 조작 가능한 원본은 HTML이다.
- 경로 좌표 투영과 이전 공식 분홍선 픽셀을 비교한39개 표본 중37개가3px 이내, 거리 중앙값0.39px다. 출발/도착 마커로 가려진 부분이 있어 모든 표본 일치를 주장하지 않는다. 위치/경로의 현장 측량 검증과 구분한다.
- 관리된 Chromium의 file URL 차단은 로컬 HTTP 서버로 열어 해결했다. 인증/브라우저 정책을 해제하지 않았다. 외부 지도 재수집은 같은 카메라의 배경1회이며 기존 앱 빌드/기기 검사는 반복하지 않았다.
