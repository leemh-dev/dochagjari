# 판교점 5층 에뜨와 · 채팅용 실제 경로 예시

2026-11-13 UTC · 앱 변경 없이 공식 사이트를 Chromium에서 열어 지도와 길찾기를 실행했다. 실제 현장 이동/차량 내비/실내 측위/앱 구현 증거는 아니다.

## 실제 지도 경로

[공식 층별 안내](https://www.ehyundai.com/newPortal/DP/FG/FG000000_V.do?branchCd=B00148000)의 5층 안내도에서 에뜨와 POI `PO-AE7oOvIjQ9013`을 확인했다. 지도 왼쪽 위 유아차 대여/유아휴게실 쪽 엘리베이터 POI `PO-hpuc3mdcR3562`, 매장 앞쪽 에스컬레이터 POI `PO-qMsObl1FM4396`를 각각 출발점으로 공식 지도 `getRouteOn`을 실행했다. 선을 임의로 그린 이미지가 아니라 공식 길찾기 결과 캡처다.

- [엘리베이터→에뜨와](elevator-to-ettoi.png): 유아차 대여/유아휴게실 쪽 복도로 이동해 블루독베이비·밍크뮤 매장 블록을 돌아 에뜨와 입구로 연결한다. 방향은 지도 기준이며 실제 엘리베이터에서 내리는 방향과 구분한다.
- [에스컬레이터→에뜨와](escalator-to-ettoi.png): 에뜨와 앞쪽 에스컬레이터에서 같은 층 매장 입구로 연결한다. 5층 내 보행선은 더 짧게 보이지만 지하 주차장부터의 총 이동/대기 시간 비교가 아니다.
- [5층 전체 보기](floor5-overview.png) · [정제한 두 경로 결과](route-result.json).

유모차/휠체어 동반은 엘리베이터를 우선하는 제안이다. 해당 경로의 모든 무단차/문폭을 현장 검증한 것은 아니다. 성인만 이동하면 에스컬레이터도 후보지만 운행/대기·출발 주차층에 따른 총 이동을 측정하지 않았으므로 더 빠르다고 단정하지 않는다. 원시 거리 단위/축척을 검증하지 않았으므로 m 거리와 실제 이동 시간을 표시하지 않는다.

## 주차/게이트 조사 결과와 연결 한계

[공식 판교점 문화센터 강좌 안내](https://ehyundai.com/newCulture/CT/CT010100_V.do?crsCd=573&crsSqNo=25138&ctGubn=&proCustNo=P02568281&sqCd=061&stCd=480)의 2026-11-27 강좌 상세에서 지하3~6층 C1~C3 구역과 5·6호기를 이용하는 **9층 문화센터 개점 전 방문** 안내를 확인했다. C1~C3은 구역 표기이며 특정 주차면/기둥/빈자리 증거가 아니다. 이 정보를 에뜨와 최적 주차 위치나 위 5층 지도 엘리베이터와의 동일 호기 증거로 확대하지 않는다.

같은 공식 안내의 7번 게이트는 발렛데스크 쪽 **보행 출입문**이며 차량 주차장 진입 번호가 아니다. [공식 위치/주차 안내](https://www.ehyundai.com/newPortal/DP/WC/WC000000_V.do?branchCd=B00148000)는 확인했지만 현재 차량 게이트 번호·정확한 진입 좌표/기둥별 연결은 이번에 확보하지 못했다. 검색된 과거 CGV 3번 출입구·J기둥 팁은 시점/목적지/주차장 문맥이 달라 이 경로의 확정 안내에 사용하지 않는다.

## 실행/검사

- Cloud 환경 스킬의 실행/네트워크 지침과 환경 상태 확인, Playwright/Chromium 사용. 샌드박스 소켓 제한으로 처음 실행 실패 후 승인된 환경에서 실행했다.
- 기본 Headless UA는 빈 모바일 페이지로 이동했다. 정상 데스크톱 UA와 환경 프록시로 공식 PC 지도/5층 선택/팝업을 열어 map ready, page errors 0을 확인했다. 지도 세션 유지 시도 한 번은 TargetClosed로 실패했고 이후 동일 PC 지도 절차로 길찾기·캡처를 완료했다.
- 최초 비교 과정에서 여러 출발 마커가 남아 최종 증거에서는 이전 경로/마커를 지우고 두 경로를 각각 캡처했다. 실제 페이지 화면을 공유했으며 사전 그림/생성 이미지가 아니다.
- 공개 매장/경로 필드와 스크린샷만 보관한다. 원본 DOM/브라우저 상태/지도 인증 구성은 저장소·artifact에 올리지 않는다. 앱·서버·APK 변경이나 Pleos/실차 검증은 없다.

다음 확보 대상은 차량 진입점과 주차 구역→특정 승강기→5F 출구의 연결이다. 층별 경로선 가능성은 확인했으며 기존 앱 DB/지도 재사용 구현 및 공개 배포 허용 범위는 별도 확인한다. 공식 홈페이지에서 지도가 보인다고 제3자 지도 SDK/자료를 앱에 자동 재사용할 권한이 생기는 것은 아니다.
