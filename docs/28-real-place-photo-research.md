# 실제 장소 사진으로 시나리오 재검토

후속 사용자 요청으로 사진의 형태를 단순화한 [3분할 3D UX 시안](29-photo-based-3d-ux.md)을 만들었다. 이는 아래 사진 조사 이후의 개념 설계이며 실측 재구성/센서 인식 결과나 최신 시설 사실로 표시하지 않는다. 아래 조사 시점의 기록과 원본은 보존한다.

2026-11-13 UTC. 사용자가 생성 시안이 지나치게 AI 이미지처럼 보인다고 지적하고 분당서울대병원·분당 학원가·인천공항 장기주차장·정자역의 실제 사진을 요청했다. 기존 시안/앱은 보존하며 다음 디자인은 실제 자료를 먼저 대조한다.

## 이전 생성 시안과의 관계

[docs27](27-scenario-ux-concepts.md)의 가상 병원·학원·역·공항 도형은 레이아웃/색/행동을 검토한 자료다. 실제 시설의 건물·차량 입구·주차장 배치처럼 사용하지 않는다. 이번 사진 조사 뒤 추가 가상 시설 이미지를 생성하거나 기존 시안을 실제 사진으로 바꿔 표시하지 않았다.

후속 디자인은 아래 순서로 검토한다.

1. 실제 사진에서 초행자가 알아볼 수 있는 건물 외관·입구·현장 표지를 고른다. 촬영 시점/현재 상태와 재사용 조건을 확인한다.
2. 공식 안내도와 필요한 출입구·차량 접근·승강/보행 연결을 대조한다. 사진에서 보이지 않는 연결은 현장/운영 안내로 보완하며 추정 선을 그리지 않는다.
3. 이 자료 위에 필요한 지점/다음 행동만 읽기 쉬운 UI로 표현한다. 사진의 실제 지형을 생성 이미지로 재구성해 사실처럼 만들지 않는다.
4. 병원은 동행/무단차, 픽업은 접근점/대기, 역은 사람 출구와 차량 승차점, 공항은 단기/장기/예약 주차·도착층·마중 대기의 다른 목적을 구분한다.

## 경계와 남은 자료

학원가 셔틀버스와 학부모 픽업 대기는 다르다. 실제 분당 학부모 승용차 픽업 사진은 장소·상황이 확인된 추가 자료가 필요하다. 다른 지역의 혼잡 사진으로 채우지 않는다. 2022~2024년 게시 사진과 게시/촬영일 미확인 자료가 포함되므로 최신 현장을 확인했다고 쓰지 않는다.

외부 사진은 참고용이며 앱 배포 자산으로 편입하지 않았다. GitHub에는 출처/파일 식별/조사 기록을 남겼고 로컬에는 사진·HTML 갤러리·다운로드 ZIP을 보관한다. 공개 CDN 만료 파라미터는 게시 metadata에서 제거했다. 실제 사용자 비밀값·개인 이동 기록은 수집하지 않았다.

이번 작업은 자료 조사다. 앱0.9.0/9·e2b93ba·DB/설정/알림·APK/서명·기존 검증 수준은 그대로이며 새 코드·빌드·기기/SDK/카메라 검사·주차 추천 구현을 수행하지 않았다.
