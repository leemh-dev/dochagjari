## 이번 구현 선택

- 상단 영상은 사용자가 선택한 동봉 생성영상이며 OEM 외부카메라를 흉내 낸 실연동이 아니다. 닫기/ON_STOP/주행/주차완료에서 미디어·관측을 중지하고 자동재개하지 않는다.
- 하단 주차/도로 지도는 UI 배치 예시다. 현재위치·실측 주차층·기둥·승강 연결·허용 정차점을 생성하지 않는다.5층 경로만 기존 공식기반 개략도를 재사용한다.
- 병원/학원 패널의 후보/차량 높이·명시이동조건/동행주차/제외는 기존 Recommender를 사용한다. 독립패널의 모의요청이 매장 방문이나 확정 알림을 교체하지 않는다. 역/공항은 실제 승차점 근거가 없어 자동 목적지요청을 하지 않는다.
- 탑승의 사용자 확인 역할/이번구성은 DataStore에 저장하며 좌석센서와 별개다. 재시작하면 지난 구성으로 표시하고 재확인 전 이번구성으로 적용하지 않는다. 실제 음성 결과만 SPEECH 출처이며 텍스트는 TEXT다.
- 오늘 시연 범위에서 LLM/전국 시설검색 worker를 추가하지 않았다. 저장된 공식기반 판교점 자료와 출처 표시 fixture를 쓰며 이동 중 AI 보완은 후속 단위다.
- 앱마켓 출시/제출서명은 범위 밖. debug/test 개발서명·release unsigned. 실제SMS 공급자수락/수신, 외부카메라, 실차, 실측지도는 미검증이다.
